# Чеклист показа MVP заказчику (Windows + MS Project)

Прогон перед встречей. Цель: за 2–3 минуты показать цепочку  
**ввод объёмов → Mode1 → скачать .mpp → открыть в Project**.

## Подготовка машины

1. Windows с установленным **MS Project**.
2. Python venv: `pip install -r requirements-demo.txt` (должен подтянуть `pywin32`).
3. Sample `.mpp` лежит в `sample_data/` (имя как в README).
4. Запуск:
   - `uvicorn api.main:app --reload --port 8000`
   - `cd frontend && npm run dev` → http://localhost:5173

## Скрипт показа

1. Открыть форму (disclosure с формулами **свёрнут** — не раскрывать без вопроса).
2. Выбрать объект и наименование работ — ID и ВОР подставляются сами.
3. Показать план/факт по неделям и авто-отклонение.
4. **Сохранить и пересчитать**.
5. В карточке результата показать блок **Начало → Окончание**, остаток дней, факт периода.
6. Строка «Обновлена задача Id … · Начало … → … · Окончание … → …».
7. В верхней панели действий **Скачать .mpp** → открыть в Project → показать обновлённые даты у задачи.

## Критерии «готово к показу»

- [ ] Тост успеха после пересчёта; «Скачать .mpp» в панели действий ведёт на файл (или честный тост без Project).
- [ ] На машине без Project тост и подпись в результате честные (расчёт есть, файла нет) — без упоминания Mac/XML.
- [ ] ВОР и режим не редактируются вручную; режим подписан как Mode1.
- [ ] Нет красных полей до нажатия кнопки.
- [ ] Сценарий проходит без Streamlit и без пояснений «это временный демо-хак».
